# Logo Pack Studio V14

Webapp HTML/CSS/JavaScript para GitHub Pages e Android. Publica `index.html` na raiz do repositório.

## Resultados

1. **Brand Board PNG** — grelha editorial única em 3:2.
2. **Brand Guidelines PDF** — 20 páginas A4, rasterizadas.
3. **Complete Brand Pack ZIP** — inclui PNG, PDF, logótipos originais, versões monocromáticas (quando a imagem tem transparência), paleta, favicons PNG, assets sociais e fotografias carregadas.

## Notas

- Não utiliza CDN, bibliotecas externas ou Service Worker.
- A versão monocromática exige SVG/PNG com transparência; fundos opacos não são removidos automaticamente.
- PDF é rasterizado, não vetorial nem CMYK certificado.
- Fontes enviadas devem ter licença de uso/distribuição adequada.
- Fotografias e elementos gráficos opcionais podem ser adicionados.
